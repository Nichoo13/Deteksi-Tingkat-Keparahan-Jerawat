# 🌟 Deteksi Tingkat Keparahan Jerawat (Acne Severity Detection)

Selamat datang di repositori **Deteksi Tingkat Keparahan Jerawat**! 
Aplikasi berbasis *web* ini dirancang untuk membantu pengguna mengenali dan menganalisis tingkat keparahan jerawat pada wajah secara otomatis menggunakan teknologi pemrosesan gambar (*Computer Vision*).

## 📖 Tentang Proyek Ini

Banyak orang kebingungan menentukan langkah perawatan wajah karena tidak tahu seberapa parah kondisi jerawat mereka. Aplikasi ini hadir untuk memberikan analisis awal yang cepat dan mudah dipahami. Pengguna cukup mengunggah foto wajah, dan sistem akan memproses gambar tersebut untuk mengidentifikasi area jerawat.

Proyek ini sangat cocok bagi siapa saja yang tertarik belajar tentang penerapan *Machine Learning* dan pengolahan citra digital di bidang kesehatan kulit.

## ✨ Fitur Utama

- **Unggah Gambar Mudah:** Antarmuka yang ramah pengguna untuk mengunggah foto wajah langsung dari perangkat.
- **Analisis Instan:** Memproses gambar secara otomatis untuk mendeteksi jerawat.
- **Tampilan Interaktif:** Hasil deteksi ditampilkan dengan jelas tanpa istilah teknis yang membingungkan.

## 🛠️ Teknologi yang Digunakan

Aplikasi ini dibangun menggunakan alat-alat canggih namun efisien:
- **Python:** Bahasa pemrograman utama.
- **Streamlit:** Untuk membangun antarmuka web interaktif yang cepat dan cantik.
- **OpenCV (`cv2`):** Untuk memproses dan menganalisis piksel gambar secara mendalam.
